# Emergency Ops - Intelligent Command Center

A high-performance emergency response and directory platform built with Next.js, Supabase, and Google Maps.

## Features
- **Real-time Incident Reporting**: Immediate protocol activation with GPS tracking.
- **Intelligent Directory**: Organized matrix of emergency units with direct contact capabilities.
- **Admin Command Center**: Real-time monitoring of active and inactive incidents.
- **Multi-language Support**: Seamless Spanish/English switching.
- **Agentic SOS**: Automated response protocols with AI-ready infrastructure.

## Tech Stack
- **Frontend**: Next.js 16 (Turbopack), Framer Motion, Lucide Icons.
- **Backend**: Supabase (Auth, DB, Real-time).
- **Maps**: Google Maps JavaScript API.
- **Styling**: Tailwind CSS 4 with Premium Emergency Theme.

## Project Structure
`emergency-ops-app/`
- `app/`: Next.js pages and layouts.
- `components/`: Reusable UI modules (Dashboard, Contacts, SOS, Auth).
- `hooks/`: Custom state management and data fetching.
- `lib/`: Utilities, translations, and global configurations.
- `services/`: API integration layers.

## Deployment
1. Set up environment variables in `.env.local`.
2. Run `npm run build` to generate the production bundle.
3. Deploy to Vercel or your preferred hosting provider.
