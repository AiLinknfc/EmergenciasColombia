## 6. Derechos de los Titulares

Los titulares de datos personales tienen los siguientes derechos:

### 6.1 Derechos Principales

1. **Derecho de Acceso:** Conocer, actualizar y rectificar sus datos personales.
2. **Derecho de Supresión:** Solicitar la eliminación de sus datos cuando no sean necesarios.
3. **Derecho de Revocación:** Revocar el consentimiento otorgado en cualquier momento.
4. **Derecho de Oposición:** Oponerse al tratamiento de sus datos para fines específicos.
5. **Derecho de Portabilidad:** Solicitar una copia de sus datos en formato electrónico.
6. **Derecho de Información:** Ser informado sobre el uso de sus datos personales.

### 6.2 Procedimiento para Ejercer Derechos

Para ejercer cualquiera de estos derechos, el titular debe:

1. Enviar una solicitud escrita a: **soporte@ailink.com.co**
2. O llamar al: **316 497 6104**
3. O presentar PQRS al: **310 695 1743**

La solicitud debe contener:
- Nombre completo del titular
- Documento de identidad
- Derecho que desea ejercer
- Descripción de la solicitud
- Medio de respuesta preferido

**Tiempo de respuesta:** Máximo 15 días hábiles desde la recepción de la solicitud.

## 7. Medidas de Seguridad

### 7.1 Medidas Técnicas

- **Encriptación:** Todos los datos sensibles se almacenan encriptados
- **Autenticación:** Sistema de autenticación robusto con tokens JWT
- **HTTPS:** Todas las comunicaciones se realizan mediante protocolo seguro
- **Backups:** Copias de seguridad encriptadas y regulares
- **Firewalls:** Protección contra accesos no autorizados
- **Monitoreo:** Sistema de detección de intrusiones 24/7

### 7.2 Medidas Administrativas

- **Políticas de acceso:** Solo personal autorizado puede acceder a datos
- **Capacitación:** Personal capacitado en protección de datos
- **Contratos de confidencialidad:** Todo el personal firma acuerdos de confidencialidad
- **Auditorías:** Auditorías de seguridad periódicas

### 7.3 Medidas Físicas

- **Servidores seguros:** Infraestructura en centros de datos certificados
- **Control de acceso:** Restricción física a servidores y equipos
- **Dispositivos seguros:** Equipos con protección antivirus y actualizados

**Proveedores de servicios:**
- **Supabase:** Servicios de base de datos y autenticación (cumple con GDPR)

### 16.2 Registro de Aceptación en Base de Datos

```typescript
// services/data-policy.service.ts
import { createClient } from '@/lib/supabase/client'

export async function recordPolicyAcceptance(userId: string, policyVersion: string) {
  const supabase = createClient()
  
  const { data, error } = await supabase
    .from('data_policy_acceptances')
    .insert({
      user_id: userId,
      policy_version: policyVersion,
      ip_address: await getClientIP(),
      user_agent: navigator.userAgent,
    })
    .select()
    .single()
  
  if (error) throw error
  return data
}

async function getClientIP(): Promise<string> {
  try {
    const response = await fetch('https://api.ipify.org?format=json')
    const data = await response.json()
    return data.ip
  } catch {
    return 'unknown'
  }
}
```

### 16.3 Validación de Aceptación

```typescript
// middleware.ts
import { createClient } from '@/lib/supabase/server'
import { NextResponse } from 'next/server'

export async function middleware(request: NextRequest) {
  const supabase = createClient()
  const { data: { user } } = await supabase.auth.getUser()

  if (user) {
    // Verificar si el usuario ha aceptado la política actual
    const { data: acceptance } = await supabase
      .from('data_policy_acceptances')
      .select('*')
      .eq('user_id', user.id)
      .eq('policy_version', '1.0')
      .single()

    if (!acceptance && !request.nextUrl.pathname.includes('/data-policy')) {
      return NextResponse.redirect(new URL('/data-policy', request.url))
    }
  }

  return NextResponse.next()
}
```
